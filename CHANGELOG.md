# Changelog

All notable public changes to Lotto Digit Coverage Dynamics are recorded here.

## [1.2.0] - 2026-09-19

### Added

- local/offline Svelte GUI and bilingual presentation infrastructure;
- complete annual and consolidated historical archive tooling;
- GiadaWare AI dynamic research translation boundary;
- `db ask` semantic read-query interpretation for free Italian and English
  historical queries;
- Cifrolotto-owned versioned semantic query context;
- structural SQLite read-query authority and bounded read-only executor;
- model qualification documentation and deterministic semantic-query tests.

### Changed

- documentation authority is explicitly English-first, with Italian retained as
  derived public presentation;
- database maintenance supports safe multi-year orchestration and rollover;
- CLI discovery and localization cover the expanded command surface;
- natural-language database queries now use semantic grounding rather than the
  superseded fixed-intent prototype.

### Safety and reproducibility

- model-generated SQL remains untrusted;
- DML, DDL, administrative operations, undeclared schema access and unbounded
  result execution fail closed;
- deterministic CI does not require a real LLM;
- real-model availability is explicitly separated from semantic qualification.

## [1.1.0] - 2026-07-31

- added historical occurrence tracing from a reference draw;
- added same-wheel positional highlighting and validation;
- published bilingual documentation for the feature.
